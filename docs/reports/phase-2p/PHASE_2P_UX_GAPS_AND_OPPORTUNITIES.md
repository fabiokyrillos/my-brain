## Design principles

- One obvious primary action per surface.
- Progressive disclosure instead of long pages and nested editors.
- The same action uses the same component and vocabulary everywhere.
- Machine confidence reduces ceremony only after calibration; it never hides
  uncertainty.
- Automation is visible after the fact and reversible.
- Mobile is the reference layout, not a compressed desktop layout.
- Error states say what the user can do next without exposing provider detail.

## Deliberate non-goals

This is not a new visual brand, a new database model, a new AI provider or a
permission to rewrite mature security and lifecycle contracts for aesthetic
convenience.
